BOTANIQ

Crop Recommendation & Growth Simulation

Enter your soil, climate and space values. BOTANIQ ranks the crops that will survive them and grows each one on screen. Tuned to Carmona, Cavite, with live local weather.

Download BOTANIQ.pyView on GitHub

Twelve crops, scored on eight factors

Nitrogen, phosphorus, potassium, pH, moisture, temperature, sunlight and planting space.

How it decides

Suitability. Each value is compared with the crop's preferred range. Inside it scores 1; outside it falls away smoothly, and the weighted factors are multiplied into a 0–100 score.

Survival. A crop that is far enough out on temperature, moisture, pH or light, or burned by too much fertilizer, is ruled out, whatever its score. If nothing survives, the app says so.

Growth. Vigor comes from the same factors, so a poor match grows short and sparse and a bad one dies.

Run it on your computer

Python 3 with these packages:

pip install ursina pillow pygame
python BOTANIQ.py

Put the crop pictures in an images folder and botaniq_logo.png next to the script. English and Filipino are both built in.
